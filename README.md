# Restaurant-360-Power-BI
Interactive 4-page Power BI dashboard analyzing restaurant ratings, cuisines, locations, pricing, and services.

Restaurant 360° – Power BI Dashboard

Project Overview
Restaurant 360° is an interactive Power BI dashboard developed as part of my Cognifyz internship. It explores restaurant data through four report pages to identify trends in ratings, cuisines, locations, pricing, and services.

Dashboard Pages

1. Overview
- Total restaurants, average rating, total votes, and cities
- Restaurant distribution by price range
- City-wise restaurant analysis and delivery availability

2. Cuisine & Customer Experience
- Top cuisines and cuisine combinations
- Restaurant chains and customer ratings
- Geographic distribution of restaurants

3. Geographic & Restaurant Insights
- Top 10 cities by restaurant count
- Top 10 restaurant chains by locations
- City-wise average ratings and restaurant distribution

4. Price & Services Analysis
- Online delivery by price range
- Table booking by price range
- Total votes by rating range

Tools Used
- Microsoft Power BI
- Data Visualization
- Interactive Dashboards
- Data Analysis

Key Learning
This project helped me gain hands-on experience in building interactive reports, analyzing restaurant data, and presenting information through visualizations.
